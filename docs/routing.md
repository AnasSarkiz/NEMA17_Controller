# Saved supplier-footprint routing

The fresh same-edge tscircuit local autorouter attempt reached its 90-second timeout without a completed output; no copper from that attempt was accepted. Its actual result is recorded in `artifacts/validation/same-edge-native-autorouter.json`. `artifacts/autorouted.circuit.json` is preserved historical diagnostic routing, not the accepted same-edge board. The authorized Freerouting fallback provides the accepted copper. `scripts/export-supplier-router.py` exports exact imported polygon, rectangle, pill and circle pads to `supplier-input.dsn`; Freerouting 2.0.1 output is saved in `supplier-board.ses`. `scripts/import-supplier-session.py supplier` converts that session without replacing supplier footprints.

The CH32 board uses two copper layers. RP2040 uses top / inner1 dominated by GND / inner2 signals / bottom. Inner1 has one bounded local V3V3 power bridge for the IOVDD10-to-C_IO10 bypass; general inner1 signal routing remains prohibited. RP2040 ground fills have 0.20 mm clearance and 0.35 mm edge margin. Ordinary fallback vias are 0.50/0.25 mm; two QSPI escape vias and the two local IOVDD10 bypass vias are 0.40/0.20 mm. Only grounded exposed-pad thermal vias may sit inside pads. All fitted components and paste are on top; through-hole USB shield joints require soldering.

Selected CH32 final PCB changes from the fallback session are recorded in `supplier-routing-adjustments.json`. These include grounded thermal-pad contacts, clearance-constrained width adjustments and connected ground/regulator heat copper. No native supplier land pattern was changed. `replay-supplier-adjustments.py` checks each expected before-record before applying the saved adjustment set.

Validate the final `board.circuit.json` with `npm run check`, the native-geometry `verify-connectivity.py`, `tsci check`, and all-layer 100 pixels/mm Gerber shorts analysis. These checks do not establish controlled impedance, EMC, manufacturing fit or tested hardware operation.

The current same-edge review widens saved tracks only within verified native clearances and regenerates grounded copper; superseded opposite-edge measurements are historical. Both variants use ground fills. `review-power-copper.py` performs clearance-constrained widening; `fill-ground.py` refills native-geometry pours; `audit-trace-widths.py` screens the resulting actual segments. Complete SES-to-final changes remain in the replay proof. Rerouting or replay must also recompile and merge current source metadata so the complete protected VM circuit is retained: 100 kΩ/10 kΩ input divider, default-off switch, 10 kΩ output bleed and enabled ×21 conversion.
