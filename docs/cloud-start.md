# Cloud startup

Use the existing isolated checkout `/workspace/NEMA17_Controller`. Do not create a linked worktree during onboarding. Node24/npm11, local Bun1.4.2, Java21 and a routing Python virtual environment are prepared. Use `scripts/cloud-install.sh` to restore pinned dependencies, with writable cache/config locations and TLS checks retained. No credentials are required. npm reports a skipped integrity check for the locked pcb-trace-linter Git dependency; the installer separately checks all ten executable library sources against SHA256 values verified from upstream commit 4c035f9d40ffb03ba547a08975b5e64b20371123.

First run `npm run build` and `npm run typecheck`. Build renders/checks `artifacts/board.circuit.json` without replacing saved traces. `npm run shorts` independently checks exported Gerber copper. Expected checked delivery: 311 trace sections, zero DRC errors, 22 reported warnings, no Gerber shorts. Read the report for its actual results and release blockers; don't equate DRC with physical/electrical validation.

To edit, run `npm run dev` in this checkout. The tested editor starts on port3020 and names `src/board.tsx` as the main component. Readiness checks: `curl --fail http://localhost:3020/` and `curl --fail http://localhost:3020/standalone.min.js`; root HTML must contain the main component path and the JS bundle must be nonempty. The actual source was separately compiled to Circuit JSON successfully; HTTP checks alone do not prove USB hardware or browser behavior.

Use `/workspace/.routing-venv/bin/python` for the optional copper-repair workflow in `docs/routing.md`. Keep `unrouted.circuit.json`, the DSN/map, SES and original autorouted JSON as provenance. `npm run source:check` saves a fresh `final-source.circuit.json`; it leaves the archived routing input intact. `npm run autoroute` writes a separate diagnostic result. Any source placement changes invalidate existing copper until reverified.

The manufacturer motor drawing is inaccessible under the current live network policy. Added document/vendor domains are saved only in the configuration draft; they do not change live egress. The board's four rear-adapter holes use provisional 26 mm pitch. No rear-motor fit, assembled PD/USB behavior, or USB control firmware is verified. Review and save the draft in environment settings, then publish the environment to activate the configuration/snapshot. Fresh-task snapshot restoration has not been independently tested.
