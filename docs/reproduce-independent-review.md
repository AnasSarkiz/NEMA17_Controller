# Reproduce the local independent review

Use the locked dependencies and the installed Python environment documented in the scripts. The saved routed release is `artifacts/board.circuit.json`; `index.circuit.json` is an identical delivery copy. `index.circuit.tsx` is the source entry. Native `npm run build` renders and checks the saved PCB; it does not silently replace routing with a new board.

1. Run `npm ci`, then `npm run source:check` to compile the current TSX into the unrouted source. Prepare the functional schematic using the repository build/presentation scripts; compare fresh native pads, physical pin connectivity and part values with the saved routing through `scripts/finalize-independent-review.py`. Source changes require another physical comparison and regenerated artifacts.
2. Run `/workspace/.routing-venv/bin/python scripts/run-independent-validation.py`. It executes the real typecheck, build/DRC, physical connectivity, trace widths, Gerber shorts and functional-silkscreen checks, records exit codes/log hashes and refuses unexpected saved-board changes.
3. Manufacturing export uses `scripts/export-manufacturing.py`; its `--use-existing-raw` option is allowed only when the recorded raw/source hashes match. Audit the actual ZIP with `scripts/audit-manufacturing.py --render`, `scripts/audit-outer-power-cam.py` and `scripts/inspect-via-paste.py`. Archive notes, Cu/drill bytes, assembly process tables and current source must agree.
4. Mechanical STEP intersection review is in `scripts/review-mechanical.py`; use the exact script/help in this checkout for arguments. Generate assembly/harness drawings with `scripts/service-release-drawings.py` and `scripts/draw-service-harness.py`. A source-hash rebind is justified only after the script proves unchanged native component geometry; it is not a substitute for reviewing moved components.
5. Render the actual A4 PDF with `scripts/export-a4-pdf.py`, rasterize and visually inspect every page, and run the project browser checks. `scripts/check-service-cli.py` records the real CLI source/netlist/pin/schematic/placement results. Placement/pickup advisories and the unavailable `pcb-style` command remain disclosed. These are not official IDE or electrical simulation results.
6. Run `scripts/calculate-operating-envelope.py`, then `scripts/finalize-independent-review.py`. The latter proves fresh source versus saved pads/connectivity, checks all current evidence bindings, checks archive-member equality and rehashes every final inventory entry. Make local commits only. No publication or order is authorized by this review.

RP2040 routing history preserves the official native-router attempt, corrected DSN fixed-wire export, official FreeRouting SES and specific manual copper repairs. Replaying the saved, hashed SES is the reproducible input for those ID-specific repairs. A new autorouter result requires a new review; never apply the recorded repair IDs indiscriminately. FreeRouting's intermediate incomplete result was not accepted as a passing board. Final actual copper audits caught and removed an obsolete PD stub that the native check missed.

The operating-envelope document and final manifest are current. Older thermal/routing/power-sequencing/publication reports are historical; see the historical evidence README. Hardware measurements and supplier approval cannot be reproduced from software alone and remain open in the bring-up checklist.
