# Engineering verification and construction history

Current authoritative evidence: `final-engineering-verification.json`, `schema-verification.json`, `usb-verification.json`, `export-policy.json`, the current `artifacts/resume-validation.json`, manufacturing audit and JLCPCB order-review receipt. Each binds to the final saved board hash.

Other files here are construction/baseline snapshots or intermediate diagnostics and can contain failures or subsequently replaced routes. They are retained to explain the engineering work and must not be used as current manufacturing input. The default Gerber archive and the separate JLCPCB review handoff are the qualified outputs. `upstream-native-gerbers.zip` is diagnostic exporter output.
